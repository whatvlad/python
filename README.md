# Python learning exercises

A collection of small scripts and coursework exercises created while learning Python fundamentals.

## Topics covered

- variables, conditions, and loops
- functions and basic data structures
- file and error handling
- introductory HTML/CSS experiments
- small classroom and homework tasks

## Running an exercise

Use a recent Python 3 release:

```bash
python path/to/exercise.py
```

Each file is an independent exercise rather than part of one application.

## Status

**Learning archive — not actively maintained.** Never commit credentials or API tokens to source control; local secrets should be stored outside the repository.
